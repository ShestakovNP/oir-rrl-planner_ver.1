- Дифракция на препятствиях теперь считается по МСЭ-R P.526 методом нескольких изолированных цилиндров: каждое препятствие, которого касается «натянутая нить» профиля, — скруглённая вершина с радиусом по профилю, участки между препятствиями добавляют потери по наименьшему просвету. На трассах с одним острым препятствием результат почти не меняется, на трассах с несколькими препятствиями и широкими холмами потери честнее (больше).
